# 💖 Be My Valentine? - Romantic Quest 💖

A beautiful interactive web application designed as a love quest with 5 sequential tasks, each containing poetic riddles about meaningful places in a relationship.

## 🌟 Features

- **Romantic Landing Page** with animated floating flowers, hearts, and sparkles
- **5 Progressive Tasks** with beautiful poetry-style riddles
- **Interactive Animations** including floating elements, confetti explosions, and heart bursts
- **Playful Valentine Question** with a "NO" button that runs away when hovered
- **Responsive Design** that works on both desktop and mobile
- **Smooth Transitions** and romantic styling throughout

## 🎯 How It Works

1. **Landing Page**: Beautiful animated background with the quest introduction
2. **Task System**: 5 sequential tasks that unlock after correct answers
3. **Poetic Riddles**: Each task contains romantic poetry referencing meaningful places
4. **Progress Tracking**: Visual progress bar showing completion status  
5. **Final Question**: Culminates in the Valentine's question with special interactions
6. **Celebration**: Confetti and heart burst animations upon acceptance

## 📋 Task Structure

Each task includes:
- A romantic, poetic riddle
- An input field for the answer
- A gentle hint button
- Success animations with floating hearts
- Progress tracking

## 🔧 Customization

To customize for your own relationship:

### Update the Answers
In `index.html`, change the `data-answer` attributes:
```html
<input type="text" class="answer-input" data-answer="your-custom-answer">
```

### Modify the Riddles
Update the riddle text in each task section to reflect your own memories and places.

### Change the Styling
Modify `styles.css` to adjust:
- Color schemes
- Animation speeds  
- Font choices
- Background effects

## 🎵 Adding Background Music

To add romantic background music to the final page:

1. Add your music file to the project folder
2. Update the audio element in `index.html`:
```html
<audio id="background-music" loop>
    <source src="your-romantic-music.mp3" type="audio/mpeg">
</audio>
```

## 🌐 Running the Application
